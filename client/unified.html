Cổng API & Tích Hợp Hệ Thống

Kết nối chuẩn OpenAI Speech API (`POST /v1/audio/speech`) cho các ứng dụng Voice Bot, LiveKit, Pipecat.
Endpoint: POST http://localhost:8000/v1/audio/speech

Tương thích 100% với OpenAI SDK, bạn chỉ cần đặt base_url="http://localhost:8000/v1".

curl -X POST http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model": "adragon-v3-turbo", "input": "Xin chào thế giới!", "voice": "Nhật Phong"}' \
  --output test.wav

Hướng Dẫn Sử Dụng Nhanh

Tài liệu hướng dẫn tối ưu chất lượng âm thanh và khai thác tối đa sức mạnh mô hình.

1. Voice Cloning: Nên chọn đoạn audio mẫu từ 3–8 giây, người nói phát âm rõ ràng, không có nhạc nền to.
2. Cảm xúc: Bạn có thể chèn các thẻ thử nghiệm như [cười], [thở dài] vào văn bản.
3. Song ngữ: Thoải mái pha trộn từ tiếng Anh (code-switching) vào câu tiếng Việt.
